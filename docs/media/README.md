视频展示本项目的真实界面和实际导出作品，使用公开古典诗文；纸纹、装裱和印章均由应用自身渲染。开头缓慢开卷，中段展示操作与结果，最后缓慢收卷。

视频使用的马善政楷书、龙藏手写体与全字库说文解字字体，其来源和许可参见[项目说明](../../README.md#来源与许可)及[字体声明](../../dist/fonts/NOTICE.txt)。视频中未附带字体文件、浏览器账户界面或个人草稿。
