# Vercel 邀请试用

首页直接开放基础创作。Vercel 上使用服务端共享邀请码解锁高级功能，不需要注册或数据库。验证在当前页完成，不会清空正文或临时导入的字体；这台设备可记住 30 天。编辑页提供「邀请试用」与「退出试用」。共享码可以转发，不是一次性或一人一码。

| 基础功能，无需邀请 | 邀请试用 |
| --- | --- |
| 录文、经典检索、内置与本机导入字体 | 横向手卷 |
| 三种宣纸纹理、清润／浓／淡墨 | 卡纸、宋锦与木框装裱 |
| 册页与长笺、自动分页预览、逐页 PNG | 整篇多页 PDF |
| 题款与基础白文篆书印章 | 朱文印、印泥微残、切换或导入印章字体 |
| 素宣壁纸、素墨、选句、章法与 PNG | 壁纸彩笺与茶褐、石青、朱砂、泥金配墨 |

单页 PDF 也保持开放。取消验证会保留原选择；验证成功后自动应用刚才点击的高级选项。退出后显示基础版本，原有高级草稿设置仍保存在本机，再次解锁后恢复。

## 本机准备

```sh
npm ci
npm run invite:setup
npm run dev:invite
```

邀请模式启动命令使用 Node.js 20.6+ 的 `--env-file` 参数。推荐使用当前 Node.js LTS。

第一次准备时会自动生成邀请码和随机会话密钥。重复运行 `invite:setup` 会保留已有有效值。

- `.env.local`：本机测试配置。
- `artifacts/invite/vercel-env.txt`：用于填写 Vercel 环境变量的私密副本。

这两个位置都已被 Git 和 Vercel 上传规则忽略。**只把邀请码发给朋友，不要分享会话密钥或整个配置文件。**

直接运行 `npm run dev` 仍是无需邀请的本机开发模式；需要测试邀请流程时使用 `npm run dev:invite`。

## 部署设置

在 Vercel 导入 GitHub 仓库时，**Root Directory 保持仓库根目录，不要改成 `dist`**。仓库根目录包含邀请验证函数；无需整站拦截中间件。

| 设置 | 值 |
| --- | --- |
| Framework Preset | Other |
| Output Directory | `dist`，由 `vercel.json` 指定 |
| Build Command | 无需前端构建，不添加自定义命令 |
| Install Command | 使用默认的 npm 安装流程 |

在项目 Environment Variables 中添加以下服务端变量，并勾选需要启用的 Production / Preview 环境：

| 变量 | 含义 |
| --- | --- |
| `INVITE_CODE` | 共享邀请码；可从本机私密配置复制，规范化后至少 8 个字符 |
| `INVITE_SESSION_SECRET` | 随机会话签名密钥；使用脚本生成的值，不发给访客，至少 32 个字符 |
| `INVITE_ENABLED` | `true` 启用高级功能邀请，`false` 开放全部功能；Vercel 上不填写时默认启用邀请 |

**不要使用 `NEXT_PUBLIC_`、`VITE_` 等前端公开变量名前缀。** 变量更新后需要重新部署才能生效。

缺少必要配置或验证服务暂时不可用时，基础创作仍可使用，高级功能保持锁定；验证接口返回配置提示。普通本机开发模式开放全部功能。

## 换码与关闭

```sh
npm run invite:rotate
```

这会在本机生成新邀请码并更新私密配置。把新的 `INVITE_CODE` 更新到 Vercel 后重新部署，旧邀请码和旧登录凭证就会失效。保留会话密钥即可；更换密钥也会使旧凭证失效。

公开开放时，在 Vercel 设置 `INVITE_ENABLED=false` 并重新部署。本机可运行 `npm run invite:off`，然后重启邀请模式开发服务器。

## 访问与隐私

- 编辑页和静态素材公开；浏览器根据验证接口的状态展示功能。邀请机制用于小范围体验管理，**不是付费授权或防破解系统**：生成逻辑在开源客户端中，修改客户端可绕过界面限制。严格商业权限需要将受限处理放在服务端校验后执行。
- 邀请码在服务端比较；浏览器不会得到配置中的邀请码或签名密钥。
- 登录凭证经过 HMAC 签名，使用 HttpOnly、SameSite=Lax Cookie；HTTPS 部署额外使用 Secure。
- 不记录访客姓名、邀请码输入日志或作品正文；书法草稿、字体导入和作品生成继续留在浏览器内。
- 不包含一次性邀请、单人配额、访客管理或跨实例的全局限流；需要这些能力时再引入存储。
- 开源代码仍然公开，不限制他人克隆和自行部署开源项目。
- **只上传 `dist/` 到 GitHub Pages 或其他纯静态托管时，验证接口返回 404，全部功能开放。** 支持验证的主机必须正确提供 `/api/invite`，不要将该接口重写成静态 404。

配置依据：[服务端函数](https://vercel.com/docs/functions/quickstart)、[环境变量](https://vercel.com/docs/environment-variables)。
