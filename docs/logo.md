# 字里行间站标

当前站标采用朱砂方印与白色毛笔「字」，同时用于页眉和浏览器标签页。

- 图标文件：[`dist/favicon.svg`](../dist/favicon.svg)，96 × 96 矢量画布。
- 印面颜色：朱砂 `#993f30`；字色：纸白 `#f6f3e9`。
- 字形来源：马善政字体；已转换为路径，不依赖访客安装字体，也不额外下载字体。
- 页眉随现有响应式样式缩放；浏览器标签页直接使用同一 SVG 图标。

字体版权和许可见[第三方声明](../THIRD_PARTY_NOTICES.md)及[马善政 OFL 原文](../dist/fonts/MaShanZheng-OFL.txt)。
