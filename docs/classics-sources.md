# 诗文选：篇目与版本

内置 24 篇公版古诗文，按通行简体独立录入，仅包含原文，没有复制现代译文、注释、网页排版或第三方诗词数据集。文本可在本机编辑，运行时不请求外部诗词接口。

参考文库中的古籍可能保留异文及繁体字；本项目采用适合日常书写的通行简体，不作为校勘定本。重点核对了《静夜思》《山居秋暝》《爱莲说》《水调歌头》的原文与异文说明。其他篇目提供校阅入口供复核；批量自动对勘因繁简差异与文库限流未完成，不将结构测试等同于逐字校勘。

## 版本说明

- 《静夜思》采用《唐诗三百首》常见的「床前明月光」「举头望明月」版本。
- 《水调歌头》录正文、不含小序，采用「又恐琼楼玉宇」「何事长向别时圆」。
- 《爱莲说》采用常见的「世人甚爱牡丹」写法；部分古籍作「盛爱」。
- 《鹿柴》保留「返景」写法。
- 《望庐山瀑布》录组诗中的完整七言绝句，非五言古诗。
- 《兰亭集序》明确标为节选，范围从「永和九年」至「感慨系之矣」。
