# 书法排版工具

在浏览器里录入诗文，选择字体、纸张与装裱，排成一幅可以保存的竖排书法。

纯静态应用，无需账户、数据库或 API 密钥。排版、字体导入与图片生成均在当前浏览器完成。

![诗文选与册页预览](docs/images/preview.png)

## 功能

| 功能 | 说明 |
| --- | --- |
| 经典诗文 | 内置 970 篇，涵盖唐诗、宋词、《诗经》《论语》及常用古文；支持文集、体裁、篇名、作者和诗句检索 |
| 选篇预览 | 先看原文，再明确载入；本次会话内可撤回最近一次载入，恢复原稿与页码 |
| 竖排章法 | 从右向左排版，支持诗文册页、舒朗长笺及 16 / 24 / 36 列横向手卷；长文自动分页，保留全部正文 |
| 展卷鉴赏 | 全视口欣赏作品，支持放大、缩小、滚轮缩放、鼠标拖动和键盘翻页；首屏作品由本站排版引擎实时绘制 |
| 书写字体 | 内置马善政楷书、龙藏手写体，支持设备字体及本机导入 TTF、OTF、WOFF、WOFF2 |
| 纸墨效果 | 暖米生宣、月白熟宣、淡茶旧笺；素笺、乌丝栏；清润、浓墨、淡墨及轻微自然变化 |
| 钤印 | 独立篆书字体，白文、朱文，新钤、古印，一至四字印面及放大预览 |
| 装裱陈列 | 纯宣纸、留白卡纸、宋锦册页、胡桃木框；另有三种案头背景 |
| 留存作品 | 当前页高清 PNG，整篇通过浏览器打印保存 PDF；本机自动保存文字与设置 |
| 诗笺壁纸 | 三种章法、五种纸色，自由编辑主副句与印文；可从册页取句，预留锁屏时钟空间，导出无水印 PNG |

## 快速开始

需要 **Node.js 20 或更高版本**。运行站点不需要安装依赖：

```sh
git clone https://github.com/foxnet66/shufa.git
cd shufa
npm run dev
```

打开 [http://localhost:4173](http://localhost:4173)。开发服务器仅监听本机回环地址；修改 `dist/` 中的文件后刷新页面即可。

已有 `dist/` 的完整副本时，也可以使用其他静态 HTTP 服务器。请通过 HTTP 访问，直接双击 HTML 可能受到浏览器对 ES modules 的限制。

## 使用

1. **录文**：输入题名、作者和正文，或展开「诗文选」，检索、预览后点击「录入此篇」。载入诗文不会改变字体、纸张和印章设置。
2. **选纸**：选择册页、长笺或横向手卷，设置字体、纸质、列数、行文方式和装裱。五言、七言可自动采用相应的每列字数。
3. **钤印**：填写落款与印文，独立选择印章字体、印式与印泥质感。留空印文可不钤印。
4. **留存**：点击「存为 PNG」下载当前页，或选择「整篇 PDF」，在系统打印窗口选择「另存为 PDF」。

页签支持左右方向键及 Home、End 键切换；多页作品使用「前页」「后页」浏览。点击「展卷鉴赏」进入全视口预览：滚轮或滑块缩放，鼠标拖动阅卷，左右键翻页，Esc 收卷；触屏设备可以滚动查看放大作品。

### 诗笺壁纸

点击顶部「诗笺壁纸」，选择一主一副、双句对读或独句留白，再配月白素宣、青瓷、黛墨泥金、朱笺或宋锦纸色。切换章法和纸色会保留已填文字。

选句分为诗词、祝愿、自勉、闲适四类，共 15 组。诗词默认采用**同字号、同字距、齐首**的双句对读；祝愿等日常寄语采用主句醒目、辅句较小的章法。9 组日常寄语为本站拟写，不署古人名。切换题材只筛选候选句，不覆盖已填文字；点选具体句子时才载入并自动匹配章法，随后仍可手动调整。

旧草稿中可识别的预置诗句会从旧默认主辅版式迁移为等大对读，文字与其他设置保留；自定义文字不会被猜测分类，新版手动选择的章法也会保留。

- 主句最多 24 字，副句最多 60 字；支持自由输入、精选诗句和「从册页取句」。取句使用册页正文前两句，超长会提示自行选句，不截断原文。
- 出处可自行填写；修改预置或提取的句子后，自动填写的出处会清空，避免误署作者。
- 独立选择内置字体，或沿用册页当前字体；印式、印章字体及印泥质感沿用册页的钤印设置，壁纸印文独立填写。
- 提供 1440 × 3120、1440 × 2560、1440 × 1920 三种画幅，以及 28%、34%、42% 顶部留白。时钟仅是位置参考，不模拟所有手机的实际锁屏布局。
- 壁纸草稿与册页原稿分别保存在浏览器本机存储中；点击选句不会覆盖册页正文。
- 「保存壁纸」导出完整 PNG，不带预览时钟、按钮或水印。下载后在手机系统中自行设置为壁纸；实际裁切取决于设备与系统设置。

纸面使用本机 Canvas 生成的纸浆起伏、颗粒与纤维纹理，宋锦另绘经纬线；彩色底纸会在着色后补绘纹理，避免纸感被底色覆盖。纹理在文字之前绘制，与纸面一起进入 PNG 和作品打印画布。这些是数字模拟，不是实拍宣纸扫描；无需购买纸纹素材，也不加载第三方纹理服务。

### 导出说明

- 册页和长笺 PNG 宽度为 **2400 像素**。手卷按卷幅增加分辨率，16 / 24 / 36 列分别为 **3258 / 4698 / 6858 像素**宽；高度随章法和装裱比例变化，界面会显示最终尺寸。
- 装裱加在画心外侧，不裁切文字，随 PNG 和整篇打印图像一起输出。
- 背景只用于页面陈列，不进入导出作品。
- PDF 为整篇册页图像，不是可选中文字的矢量文档。打印时建议关闭页眉页脚，并检查纸张和边距设置。
- 横向手卷打印到 A4 时会缩小适配纸面；保留整卷高清细节建议下载 PNG。系统打印中的最终纸张效果须自行预览确认。
- 导出前会等待字体就绪；加载失败或缺字时，界面提供提示或后备字体。

### 容量与效果

- 正文最多 4000 个字，支持选择保留标点；长文会完整分页，不会静默截断。
- 题名最多 120 字；长题款会缩小显示，也可以自拟短题。作者、落款各最多 20 字，印文最多 4 字。
- 单个导入字体文件最多 30 MB，仅当前会话有效，刷新后需重新导入。
- 这是基于字体的排版与纸墨合成。数字纸纹、墨色与印泥为视觉模拟，不生成新的手写笔画，也不声称复刻某位书法家的真迹。
- 内置诗文有版本差异与古籍异体字，未逐篇人工校勘。节选和保留的明显同名异文有说明，各篇提供校阅或来源入口。

## 部署

`dist/` 就是完整站点，**无需构建**。将其中的全部文件作为静态站点根目录发布，并保留 `assets/`、`fonts/`、`data/` 和各 JavaScript 模块的相对路径。

请只发布 `dist/`，不要将仓库根目录、`.git/`、开发依赖、本机缓存或扫描报告作为网站内容公开。部署到其他项目的子路径时，相对资源路径可以继续使用。

本项目不需要 `.env`、后端服务或访问令牌。开发用的 `server.mjs` 不作为公网服务使用。

## 本机数据与隐私

- 正文、草稿、设置和导入字体在当前浏览器处理，项目没有正文上传接口或分析统计代码。
- 草稿保存在本站的浏览器本地存储中；使用共享设备时，可在浏览器的站点设置中清除本站数据。
- 内置字体、诗文数据和图片随本站提供，不请求第三方字体 CDN、在线诗词接口或生成式 AI 服务。首次访问仍需下载本站静态资源。
- 「文本来源」「校阅参考」等链接在点击后打开相应的外部网站。
- 不要将密码、令牌、个人配置或真实用户草稿提交到 Git。忽略规则与安全检查建议见 [SECURITY.md](SECURITY.md)。

## 开发与测试

```sh
npm test
```

测试只使用 Node.js 内置测试工具，覆盖字符完整性、分页边界、题款与印章几何、字体许可与字表、诗文检索、去重和全部条目的内容校验。

### 重建诗文库

日常使用和运行测试无需安装开发依赖。仅在修改语料整理规则或重建静态数据时执行：

```sh
npm ci
npm run corpus:build
```

重建脚本使用固定的上游提交和 SHA-256 校验值；缓存保存在忽略目录 `artifacts/corpus-source/`。它保留原许可、整理简体与部分异体字、去重并生成可追溯的导入清单，遇到超长或缺损文本会报错。

繁简转换工具是开发依赖，不进入浏览器运行代码。更新文库后请运行测试，并核对新增篇目、异文说明及来源许可。

## 项目结构

```text
dist/                   完整静态站点
  app.js                编辑、草稿、字体导入与导出
  layout.js             字符分割、分页与题款布局
  renderer.js           Canvas 作品渲染
  paper.js / seal.js     纸墨与印章效果
  mounting.js           装裱几何与材质
  art-viewer.js         全视口缩放、拖动与翻页鉴赏
  wallpaper*.js / .css  诗笺壁纸、独立草稿与锁屏留白布局
  classics*.js          诗文数据、检索与选篇界面
  assets/               首页图像与图标
  fonts/                内置字体及其许可
  data/                 语料原许可
scripts/                语料重建脚本与来源版本锁
tests/                  自动测试
docs/                   版本、来源与素材制作记录
licenses/               第三方开发工具许可
server.mjs              本机静态开发服务器
```
