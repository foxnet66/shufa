# 自在小楷

独立实现的浏览器书法排版工具。没有使用参考项目的代码、图片、字库或诗词数据集，也不调用其 API。

## 运行

需要 Node.js 20+，不需要安装依赖：

```sh
npm run dev
```

打开 http://localhost:4173 。`dist/` 是完整静态网站，可部署到任何静态托管服务，也可直接打开 `dist/index.html`（部分浏览器会限制 file URL 下的 ES modules，建议使用本地服务）。

## 功能

- 自定义正文、题名、作者、篇尾落款与印文。
- 从右到左竖排；8/10/12 列，12/14/16/20 字；题名与落款各占一列。
- 最多 4000 个正文字符，自动完整分页，不静默截断。可选择去除或保留标点；空白和换行不占格。
- 暖米宣 / 月白宣，素笺 / 乌丝栏；确定性纸纹、轻微墨色和位置变化。
- 系统楷体、宋体、仿宋，以及本地导入 TTF/OTF/WOFF/WOFF2（30 MB 上限）。
- 当前页 2400 × 3000 PNG；整篇经浏览器打印保存 PDF（A4，建议关闭浏览器页眉页脚）。PDF 是册页图片，不是可选中文字的矢量文档。
- 在当前浏览器本机保存草稿；字体文件不保存、不上传。没有分析统计或外部网络依赖。

## 字体与效果边界

本项目不附带任何字体文件。默认优先使用设备上的 KaiTi / STKaiti 等楷体，没有对应字体的设备会回退到系统衬线字体。需要跨设备统一效果时，请导入具有相应使用权的字体。原文保持输入字形，不做繁简转换。

这是基于字体的书法排版与纸墨合成，未接入生成式 AI，也不声称复刻刘春霖字迹。自然墨色仅提供小幅浓淡、大小、角度和位置变化，不生成同字异形或新的笔画。印章为现用字体排印的装饰印，不是篆刻字体。

## 代码

- `dist/layout.js`：字符分割、完整分页、文件名处理。
- `dist/renderer.js`：独立 Canvas 纸张、网格、文字、落款与印章渲染。
- `dist/app.js`：表单、草稿、字体导入、翻页和导出。
- `server.mjs`：仅用于开发的本机静态服务器。

运行 `npm test` 检查长文完整性、分页边界、Unicode 字符、输入限制和下载文件名。

内置三段古典公版作品由独立录入提供示例（《山居秋暝》《赤壁》《兰亭集序》节选），不包含参考仓库的数据集。
