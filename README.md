# 书法排版工具

首页右侧提供可点击的文房静物图，可载入《山居秋暝》并进入写字区。通用「永」字图标由 SVG 路径绘制，适用 MIT。

首页静物使用内置 imagegen 生成的透明 PNG，保留其 alpha 通道；未使用第三方照片作为站点素材。在可授权权利范围内适用 MIT，仅用于界面陈列，不进入作品导出。参考来源和完整提示词见 [制作记录](docs/stilllife-image.md)。

界面以「录文 / 选纸 / 钤印」组织操作，减少重复文案与装饰；排版说明可展开，字体状态、许可和导出说明保留。

「录文」中的「诗文选」内置 970 篇经典，可按文集、体裁筛选，按篇名/作者/诗句检索。浏览与预览不修改草稿，点击「录入此篇」才载入正文；本次会话内可恢复载入前的文字和页码，纸张、字体、印章不变。仍保留三篇常用示例快捷入口。

原创代码与通用图标按 [MIT](LICENSE) 开源，可使用、修改和商用，并须保留许可及版权声明。内置字体保留各自许可，见 [第三方许可清单](THIRD_PARTY_NOTICES.md)。

本仓库为无品牌的通用版本，不包含私有角色图片、品牌图标或托管项目标识。`package.json` 的 `private: true` 仅用于防止误发布到 npm，不限制 MIT 许可下的代码使用。

采用温润纸色与安静的案头背景，按「写字 / 选纸 / 钤印」三步创作，支持键盘切换。作品及草稿在当前浏览器处理。

独立实现的浏览器书法排版工具。没有使用参考项目的代码、图片、字库或诗词数据集，也不调用其 API。

## 运行

需要 Node.js 20+，不需要安装依赖：

```sh
npm run dev
```

打开 http://localhost:4173 。`dist/` 是完整静态网站，可部署到任何静态托管服务，也可直接打开 `dist/index.html`（部分浏览器会限制 file URL 下的 ES modules，建议使用本地服务）。

## 功能

- 自定义正文、题名、作者、篇尾落款与印文。
- 从右到左竖排；8/10/12 列，12/14/16/20 字；连续行文或按原文换行分列，长行自动接列。
- 最多 4000 个正文字符，自动完整分页，不静默截断。可选择去除或保留标点；空白和换行不占格。
- 暖米生宣 / 月白熟宣 / 淡茶旧笺三种数字模拟纸质，分别调整底色、纤维密度、细纹与边缘色差；素笺 / 乌丝栏。
- 清润 / 浓墨 / 淡墨三档，按可见字形光学居中、缓慢变化的浓淡节律；竖排标点小字偏置。
- 两种范式：接近方形的诗文册页（右列独立题款），或舒朗长笺（落款跟随末列）；末页钤印，单页作品不附页码。
- 五言自动 15 字、七言自动 14 字，亦可手动指定。自然模式下册页按可见字形高度调整纵向字距。
- 白文 / 朱文两种数字印式；独立篆书、楷体、宋体或导入印章字体，不再跟随正文。单字居中、双字纵排、三字右一大左两小、四字右起纵读。
- 新钤 / 古印两档质感，区域性浓淡、沿边缺损与纤维状缺墨；实时放大印面预览。
- 内置马善政毛笔楷书、龙藏手写体（偏行草），按需加载；保留系统楷体、宋体、仿宋，以及本地导入 TTF/OTF/WOFF/WOFF2（30 MB 上限）。
- 当前页 PNG：册页 2400 × 2640，长笺 2400 × 3000；整篇经浏览器打印保存 PDF（A4，建议关闭浏览器页眉页脚）。PDF 是册页图片，不是可选中文字的矢量文档。
- 在当前浏览器本机保存草稿；字体文件不保存、不上传。没有分析统计或外部网络依赖。

## 字体与效果边界

正文字体默认优先使用设备上的 KaiTi / STKaiti 等楷体，没有对应字体的设备会回退到系统衬线字体。需要跨设备统一效果时，请导入具有相应使用权的字体。原文保持输入字形，不做繁简转换。

也可直接选择内置手写字体「马善政楷书」「龙藏手写体」。原始 TTF 来自 Google Fonts 官方仓库，未修改；完整 OFL 1.1 版权与许可分别保存在 `dist/fonts/MaShanZheng-OFL.txt`、`dist/fonts/LongCang-OFL.txt`。字体随本站托管，无第三方字体服务请求；首次选择才下载，页面刷新后会恢复所选字体并重新加载。加载失败提供重试，导出前等待字体就绪；缺少正文字符时提示系统后备字体。印章保持独立字体设置。

印章附带官方提供的「全字库说文解字」篆书字体，文件未修改，来源为数位发展部 CNS11643 中文标准交换码全字库网站。详见 `dist/fonts/NOTICE.txt` 及页面可见来源标示。该字体仅用于印章，字表不覆盖全部现代字；缺字时明确提示并整方回退到独立楷体，避免篆楷混排。导入的独立印章字体仅在本次会话有效，TTF/OTF 可读取 Unicode 字表，其他格式请结合放大印面核对。

这是基于字体的书法排版与纸墨合成，未接入生成式 AI，也不声称复刻刘春霖字迹。自然墨色仅提供小幅浓淡、大小、角度和位置变化，不生成同字异形或新的笔画。数字篆书印不代表手工篆刻真迹或古文字考证结论。

## 代码

- `dist/layout.js`：字符分割、完整分页、文件名处理。
- `dist/renderer.js`：独立 Canvas 纸张、网格、文字、落款与印章渲染。
- `dist/paper.js`：三种数字纸质的底色、纸浆云纹、纤维与细粒渲染；无外部素材。
- `dist/seal.js`：独立印面布局、光学适配及印泥压力/磨损渲染。
- `dist/font-coverage.js`：TTF/OTF Unicode 字表读取；内置字表与原字体通过测试核对。
- `dist/body-fonts.js`：内置手写字体的按需加载、状态、错误重试和字表检查。
- `dist/studio-ui.js`：纸签导航、键盘交互及 操作提示。
- `dist/studio.css`：纸墨书房视觉及响应式样式。
- `dist/app.js`：表单、草稿、字体导入、翻页和导出。
- `server.mjs`：仅用于开发的本机静态服务器。

运行 `npm test` 检查长文完整性、分页边界、Unicode 字符、输入限制和下载文件名。

内置 970 篇古诗文，包含 24 篇手录常用选篇及来源项目整理的唐诗、宋词、《诗经》《论语》。完整来源、版本、许可和重建方式见 [诗文选记录](docs/classics-sources.md)。正文不静默截断，节选及明显异文有说明。
# 装裱与案头背景

在「选纸」中可选纯宣纸、留白卡纸、宋锦册页或胡桃木框。装裱加在画心外侧，不改变文字章法或分页，随高清 PNG 与整篇打印图像一起输出；尺寸提示随所选装裱更新。织纹与木纹均为数字模拟。

预览上方「案头光景」提供亚麻晨光、胡桃暖暮、青灰静室。背景用低对比纹理与柔光衬托作品，仅用于页面陈列，不进入导出图像。背景及装裱选择随本机草稿保存。

## 品牌与发布

这份通用代码可以直接部署到任意静态托管服务。自有品牌站可以复用相同核心代码，在独立的私有仓库或本机目录维护角色、名称和品牌配置，无需重写排版功能。MIT 许可不要求公开后续私有修改。

当前版本已移除早期品牌素材；此前公开提交仍保留在 Git 历史中，新增删除提交不会清除旧版本。已有 fork 或下载副本也不会自动消失。

语料重建工具为开发依赖，已生成的静态页面与测试不需要安装依赖。更新语料时执行 `npm ci` 后运行 `npm run corpus:build`，输入版本与校验值固定，开发转换工具不在浏览器中加载。
